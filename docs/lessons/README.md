# Lessons

Programming lessons with the MINE Byte, designed for a one-hour lab session.
Each one comes with a teacher's guide and Lua solutions, which are run automatically inside a
real Byte every time MINE changes.

| # | Lesson | Concepts |
|---|---|---|
| 1 | [First steps with Byte](01-first-steps/README.md) | instruction, sequence, program |
| 2 | [Loops: rows, floors and cubes](02-loops/README.md) | loop, nested loops, area and volume |
| 3 | [Debugging: fix Byte's programs](03-debugging/README.md) | error messages; syntax, runtime and logic errors |
| 4 | [Conditions: Byte decides](04-conditions/README.md) | true and false, `if`, `while`, sensors |
| 5 | [Variables and functions](05-functions/README.md) | variable, counter, function, parameter |
| 6 | [Redstone: Byte listens and switches on](06-redstone/README.md) | input and output, events, AND / OR |
| 7 | [Sensors: Byte waits and remembers](07-sensors/README.md) | sensors, timers, `not`, memory |
| 8 | [The board: from your desk into the world](08-board/README.md) | a micro:bit or Arduino and Byte, messages, thresholds |
| 9 | [Python: data from the board, as charts](09-charts/README.md) | **Python** (14–18): lists, `max`, functions, scaling a measurement |
| 10 | [The maze: a hand on the wall](10-maze/README.md) | algorithm, `while` and `if` together, `and` / `not`, counter |
| 11 | [Treasure hunt: coordinates](11-treasure/README.md) | coordinates, variables, a function with parameters |
| 12 | [Python: the connected greenhouse (Pico 2 W)](12-greenhouse/README.md) | **Python** (14–18): average, threshold, data over Wi-Fi (IoT) |
| 13 | [Python: automatic control (micro:bit)](13-control/README.md) | **Python** (14–18): threshold, hysteresis, state |
| 14 | [Python: the level crossing (Arduino)](14-crossing/README.md) | **Python** (14–18): state machine, events from two sources |
| 15 | [The farm: rows and fields](15-farm/README.md) | nested loops, conditions, counter, area |
| 16 | [Secret messages: Caesar's cipher](16-cipher/README.md) | characters and codes, `%`, brute force (Lua or Python) |

Every lesson can be done with the [block editor](../guide/blocks.md) too: each guide has a
"With blocks" part, with block solutions that are tested automatically as well.

Lessons with missions are JSON files that anyone can write: see
[Writing a lesson with missions](../guide/lesson-format.md).

Want to write a lesson? Read [CONTRIBUTING.md](../../CONTRIBUTING.md): we are especially
looking for teachers.
